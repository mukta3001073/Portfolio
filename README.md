# Afroza Akter Mukta | Personal Portfolio

A modern, fully responsive personal portfolio website showcasing my skills, projects and background as a CSE student, web developer and robotics & embedded systems enthusiast.

🔗 **Website Link** https://protfolionet.netlify.app

📂 **Repository:** https://github.com/mukta3001073/Portfolio

---

## ✨ Features

- Clean, modern design with a consistent navy and teal colour palette
- Fully responsive layout for mobile, tablet and desktop
- Sticky navigation bar with a mobile hamburger menu and active-section highlighting
- Sections: **About Me**, **Skills**, **Projects**, **Contact**
- Smooth scrolling and scroll-reveal animations
- Working contact form (opens the visitor's email app with the message filled in)
- Clickable email, phone, GitHub and LinkedIn links
- Accessible markup and reduced-motion support

## 🛠️ Built With

- **HTML5**: semantic page structure
- **CSS3**: custom properties, Flexbox, Grid, media queries
- **JavaScript (Vanilla)**: navigation, scroll effects, form handling
- **Google Fonts**: Inter

## 📁 Project Structure

```
Portfolio/
├── index.html    # Page structure and content
├── style.css     # All styling and responsive rules
├── script.js     # Interactivity (menu, scroll effects, contact form)
└── README.md
```

## 🚀 Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/mukta3001073/Portfolio.git
   ```
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**
   (or simply double-click `index.html` to open it in your browser)

## 🌐 Deployment

The site is deployed on **Netlify** and connected to this GitHub repository, so every push to the `main` branch automatically updates the live site.
